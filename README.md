# vaccination-management-system

A dynamic, secure full-stack web application built from scratch using Core PHP and MySQL. It features role-based access control for Admins, Hospitals, and Parents to streamline vaccine administration.

## 🛠️ Tech Stack
- **Backend:** Core PHP
- **Database:** MySQL (Relational Database)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap

## 📂 Key Folders Overview
- `/admin` : Core logic for overall system and user control.
- `/hospital` : Interface and features specific to hospital/center actions.
- `/parent` : Dashboard for parents to track vaccine schedules.
- `/config` : Database connection and application configuration scripts.
- `/database` : Contains the `.sql` schema file to set up database tables.
